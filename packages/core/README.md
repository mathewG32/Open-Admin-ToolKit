# @openadminkit/core

Framework-agnostic core of [OpenAdmin Kit](https://github.com/mathewG32/openadmin-kit): module registry, deny-by-default authorization, bounded queries, field allowlisting, safe errors, and audit events.

> Pre-alpha. Not production-ready. See the main repository for docs and the security model.

Most apps use this through a transport adapter such as [`@openadminkit/express`](https://www.npmjs.com/package/@openadminkit/express).
